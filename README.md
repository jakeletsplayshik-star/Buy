# ByeByeDPI Pilot 3 — Android APK

This repository builds a separately installable test variant of EwenLoy/ByeByeDPI-x-tg using GitHub Actions. Source and native submodules are fetched during the build. This is a test build; network unblocking is not guaranteed.

Open the Actions tab and select **Build ByeByeDPI Pilot APK**. After a successful run, download **ByeByeDPI-Pilot3-APK** from Artifacts.
